# Publication Checklist

- [ ] README explains what the project does and how to run it.
- [ ] Examples use fake data only.
- [ ] Repository files and published media contain no credentials, personal data, connector exports, private notes, raw logs, or local-machine details.
- [ ] Screenshots or demos presented as runtime evidence show the real implementation; the full frame has been checked for notifications, unrelated tabs, terminal history, local paths, and bookmarks.
- [ ] `.env` files are ignored; only `.env.example`, `.env.sample`, or `.env.template` may be committed.
- [ ] License and security note are present.
- [ ] Quality checks pass locally.
- [ ] Public-repo guard or an equivalent scan has been run before publishing.
